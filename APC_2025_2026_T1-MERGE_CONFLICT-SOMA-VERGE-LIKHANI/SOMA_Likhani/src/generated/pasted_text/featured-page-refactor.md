Refine Featured Page Buttons + Final Section for Better Archive Logic

Refine the featured archive page so the action buttons and final section better match the purpose of a public archive experience.

1. Fix Button Labels (Public Viewer Context)

The current button labels feel too operational and suggest archive administration or screening activity, which does not match the public user experience.

Primary Button

Replace:

“Screen This Work”

with:

“View Film”

This primary button should represent direct viewing of the featured work in a clean and elegant way.

Secondary Button

Replace:

“Archive Record”

with:

“Full Archive Entry”

This secondary button should communicate access to deeper metadata or archival details.

Button Interaction Rule

Keep the existing button style, spacing, hover behavior, and site color system consistent with the homepage buttons.

Avoid wording that sounds administrative, scheduling-based, or curator-only.

The buttons must feel:

• viewer-oriented
• archive-appropriate
• elegant
• public-facing

2. Replace Final Section (Current “Related Archive Entries”)

The current “Related Archive Entries” section weakens the exclusivity of the featured page because suggesting other works immediately after a featured archive feels redundant and too similar to homepage browsing logic.

Replace this section entirely.

New Final Section

Use:

“Archive Process Frames”

or

“Production Frames”

Section Purpose

Instead of suggesting other archive works, the final section should deepen appreciation of the same featured project.

Use three horizontally aligned visual cards related only to the featured work.

Content of the 3 Cards

Use placeholder visuals for:

• behind-the-scenes still
• storyboard / process image
• production detail or final composition frame

Each card should have a small caption below.

Example captions:

• Storyboard Phase
• Lighting Test
• Final Composite Frame

Layout Requirement

Keep spacing aligned with the featured page grid.

The cards must feel quieter and more editorial than homepage browsing cards.

Avoid making them look like recommendation cards.

This section should feel like archival closure.

Overall Goal

The featured page should maintain exclusivity, cinematic presentation, and archival elegance.

The final section must reinforce:

• craft
• process
• documentation
• featured importance

rather than redirecting attention to unrelated works.
