Refine both the homepage featured section and the dedicated featured archive page so they feel more editorial, visually curated, and cinematic while preserving the existing site identity, fonts, color palette, and institutional tone.

Homepage Featured Section Refinement

Adjust the homepage featured section so the composition feels more intentionally balanced and premium.

Layout

Keep the left image and right content structure, but improve proportional balance:

• Left visual area should occupy slightly more width than current layout
• Right text block should align vertically with the image center rather than sitting too high
• Ensure metadata, title, description, and action button form one clean vertical reading group

Spacing

Increase spacing between:

• metadata pills and title
• title and description
• description and metadata list
• metadata list and action button

The section should feel calm, not compressed.

Metadata Refinement

The metadata block (director, production, cast) should feel lighter:

• reduce visual heaviness
• tighten label/value spacing
• maintain subtle divider treatment

Visual Goal

The homepage featured block should feel like:

• archive spotlight
• not product card
• not streaming banner
• a curated invitation to explore

Dedicated Featured Archive Page Refinement

Redesign the featured archive page layout so it follows the editorial rhythm of classic film archive pages inspired by golden-age cinema layouts, while keeping the site’s existing fonts, colors, and overall design language.

The goal is NOT to change branding, but to introduce stronger content choreography.

Layout Principle

Avoid long stacked text sections.

Break content into alternating visual and textual blocks.

The page should use changing rhythm:

visual → text → supporting card → visual → text

so the page feels curated instead of journal-like.

Top Section

Keep the existing hero area, but improve composition:

• left featured image remains large
• right metadata remains present
• curator note should no longer sit as a separate isolated box below

Instead:

Integrate curator note into the metadata zone as a lighter editorial paragraph directly below key metadata.

This reduces fragmentation.

Middle Content Recomposition

Do not stack all article text vertically.

Instead:

Create alternating sections such as:

Section A

Left:
About the Work text

Right:
Cast / collaborators card

Section B

Full-width:
Director’s note with stronger quote styling

Section C

Two-column:
Production context + archival significance

This creates rhythm similar to film editorial layouts.

Section Weight Variation

Not all sections should have equal height.

Some sections should be shorter.

Some wider.

Some visually interrupted by image blocks.

This removes document feeling.

Insert Supporting Visual Blocks

Add at least one secondary still image or archive frame between article sections.

This can be placeholder visual content for demo.

It should break reading fatigue.

Archive Screening Placement

Keep screening section lower on page, but introduce stronger transition before video:

• short section header
• archive label
• spacing before player

The video should feel intentionally introduced, not suddenly embedded.

Typography Behavior

Keep current site typography.

Do not introduce new fonts.

However:

• use stronger heading hierarchy
• slightly tighter text grouping
• stronger contrast between heading and body zones

Visual Goal

The featured archive page should feel:

• exclusive
• editorial
• cinematic
• curated
• inspired by classic film archive layouts
• not like a long journal article

Important Constraint

Do not redesign the page into a magazine style unrelated to the site.

It must still feel connected to LikhaNi.

The featured page may feel more premium, but must remain clearly part of the same platform.
